# ADR-0003: ローカルキャッシュに shared_preferences

- ステータス: Accepted
- 日付: 2026-07-28

## コンテキスト

レビュー一覧は、オフライン時や初回描画時に「直近の取得結果」を即時表示したい。
一方、本アプリのローカルデータは**単一ユーザーのレビュー一覧**という小さく単純な構造で、
複雑なクエリ・リレーション・全文検索は要件にない（スコープ外、要件定義 §2.3）。

## 決定

**`shared_preferences` に、直近取得したレビュー一覧を DTO の JSON 配列として保存する。**

- サーバを単一の情報源（source of truth）とし、キャッシュはあくまで表示補助
- 保存/読み出しは [ReviewLocalCache](../../lib/src/features/reviews/infrastructure/review_local_cache.dart) に閉じ込める
- 壊れたキャッシュは黙って破棄し、フォールバックはサーバ再取得

## 検討した代替案

### a. drift（SQLite）
リレーショナルなクエリ・リアクティブな監視・マイグレーションを備え、設計力の見せ場も大きい。
しかし本アプリのローカルデータ要件（1リストの読み書き）に対しては明確に過剰で、
スキーマ定義・生成・マイグレーションの運用コストが便益を上回る。
**「規模に見合う技術選定をする」判断として却下**（過剰設計の回避。ADR-0002 と同じ姿勢）。
将来、フィルタ/ソートや統計（要件 §2.2 の Should）を本格化する場合の第一候補として残す。

### b. キャッシュを持たない
実装は最小だが、オフライン時に何も表示できずUXを損なう。却下。

## 結果（トレードオフ）

- 得たもの: 依存とコードの最小化、オフライン時の即時表示
- 諦めたもの: リアクティブなローカルクエリ（drift なら得られたもの）
- 方針: キャッシュ形式にバージョンキー（`cached_reviews_v1`）を持たせ、将来の移行余地を確保
